# 🧮 Scientific Calculator in C++

## 📌 About the Project
This project is a Scientific Calculator developed using C++. It is designed to perform basic mathematical operations and scientific calculations through a simple, user-friendly interface.

The project was created to practice C++ programming fundamentals and understand how mathematical operations can be implemented using code.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Power calculations
- Square root
- Other scientific operations, depending on the implemented functions

## 🛠️ Technologies Used
- **Programming Language:** C++
- **Libraries:** Standard C++ Library and `<cmath>` for mathematical functions
- **Concepts:** Functions, conditional statements, user input/output, and mathematical operations

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd YOUR_REPOSITORY_FOLDER
   ```

3. Compile the C++ source file:

   ```bash
   g++ main.cpp -o calculator
   ```

4. Run the program:

   **Windows:**
   ```bash
   calculator.exe
   ```

   **Linux:**
   ```bash
   ./calculator
   ```

> **Note:** Replace `main.cpp` with your actual C++ filename if it is different. A C++ compiler such as GCC must be installed.
